# Anmol Malviya — UIUX Portfolio

A production-structured storytelling portfolio built from the Figma concept using Next.js, TypeScript, Framer Motion, and Phosphor Icons.

## Run locally

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

## Structure

- `app/` — App Router entry, metadata, and global styles
- `components/` — reusable sections and UI components
- `data/` — typed project content
- `public/` — static assets

## Main sections

- Animated hero system
- Journey timeline
- Product Systems showcase
- Capability constellation
- Contact station
